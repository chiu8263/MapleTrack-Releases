# MapleTrack

MapleTrack 是 MapleStory Worlds 的經驗值效率追蹤工具。

## 下載

- [Windows 版本](https://drive.google.com/file/d/1Q0KGCewqcO8O1p-HlGTrrtoGsZzcKB8T/view?usp=share_link)
- [macOS 版本](https://drive.google.com/file/d/1pjyiyBD_k3SyRK3zUMbGIRvyxwjpIms-/view?usp=sharing)

## 程式特色

- **經驗效率**：本次累計 EXP、近 1 分鐘與近 10 分鐘平均、最近 10 分鐘獲得量、整場平均及每小時推估。
- **升級進度**：本次經驗增加百分比、每分鐘／每十分鐘／每小時的百分比效率，以及預計升級時間。
- **即時圖表**：比較短期與長期效率，觀察不同地圖或打法的差異。
- **獨立簡易視窗**：簡易數值與圖表可置頂、拖曳、調整大小，各自設定字級、顏色與透明度。數值可選擇顯示項目及順序。
- **視窗群組**：儲存遊戲大小、螢幕位置、辨識框，以及各組簡易視窗的位置。
- **練功紀錄**：比較時間、累計經驗與效率，可重新命名、排序及多選刪除。
- **楓幣統計**：查看本次楓幣餘額淨增加量。
- **新手引導**：首次開啟會帶你設定，可隨時跳過；主畫面的「新手引導」可再次開啟。

- ## 首次設定

1. 開啟遊戲與 MapleTrack，跟著新手引導連接遊戲視窗。
2. 在「辨識設定」輸入名稱，按「新增設定」建立視窗群組。
3. 按「校準辨識範圍」框選數字。選擇項目後範例會自動切換，圖片可放大縮小。

| 項目 | 要框住的內容 |
| --- | --- |
| EXP | 經驗數字與百分比，例如 `12891755[1.42%]` |
| 楓幣 | 只框數字與逗號，避開圖示、文字標籤與邊框 |

4. 按「測試讀值」，核對遊戲數字，完成校準後開始監控。
5. 主畫面的「簡易數值」「簡易圖表」可分別開啟或隱藏視窗。滑鼠移到簡易視窗上緣，按設定圖示即可調整外觀並立即預覽。
6. 結束後按「結束並儲存」，到左側「練功紀錄」查看 Log；按「返回目前場次」切回即時畫面。

## 快捷鍵

| 按鍵 | 功能 |
| --- | --- |
| F7 | 開始／暫停，再按一次繼續 |
| F8 | 結束並儲存，接著建立新場次 |
| F9 | 顯示／隱藏簡易數值與圖表 |
| F10 | 套用群組的遊戲大小、位置與辨識框；套用後按 F7 繼續 |

## 更新與使用提醒

- 更新前先按 F8 儲存，並完全結束程式。Windows 執行新的安裝程式；Mac 以新版替換「應用程式」內的 MapleTrack。不要刪除程式資料，以保留設定與紀錄。
- 主視窗可放在遊戲後方；關閉主視窗會結束程式，簡易視窗及設定視窗也會一併關閉。
- 不同電腦的設定與紀錄不會自動同步，換電腦時需重新連接遊戲並設定辨識框。
- 畫面辨識可能出錯，換解析度或移動遊戲內面板後，請重新核對範圍。
- 楓幣包含買賣與消費，不是純打怪收入。
- 經驗百分比依目前等級換算，升級時間是推估值；跨級時可能無法完整計入升級瞬間的經驗。

MapleTrack 是非官方玩家工具，請自行確認遊戲的使用規範。
