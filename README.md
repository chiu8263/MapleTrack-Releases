# MapleTrack

MapleTrack 是 MapleStory Worlds 的經驗值效率追蹤工具。

## 功能特色

- 讀取遊戲畫面中的 EXP 與楓幣數值
- 顯示每分鐘、每 10 分鐘、每小時經驗效率
- 顯示預計升級時間與經驗趨勢圖
- 支援簡易數值與簡易圖表視窗
- 支援 F7、F8、F9、F10 快捷鍵
- 支援 Windows x64 與 macOS Apple Silicon

## 安裝

請到 Releases 頁面下載對應版本。

macOS 請下載 Apple Silicon 版本。第一次開啟時，請允許螢幕錄製及視窗控制權限。

Windows 請下載 .exe 安裝檔並依照安裝程式指示完成安裝。
